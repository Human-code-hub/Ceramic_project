# 🌐 Basic HTML + Vite Project

This is a simple front-end web project built with HTML, CSS, and Vite for fast development and module bundling.  
The project demonstrates a basic structure of a modern static website with modular JavaScript, a custom favicon, and adaptive layout.

## 🚀 Features

- Clean and responsive HTML layout
- Vite-based development environment
- Custom favicon and meta setup
- Modular JavaScript structure
- Ready for styling and extension

## 🧰 Technologies

- HTML5
- CSS3
- JavaScript (ES Modules)
- Vite

## ⚙️ Setup and Run

# Install dependencies

npm install

# Build for production

npm run build

# Run local dev server

npm run dev
